# 🎮 TrollDash 游戏设计文档

## 一、核心定位

**一句话描述**：反套路整蛊解谜游戏，翻车比通关更好玩。

**目标用户**：全年龄段（10-35岁为主），喜欢脑洞、沙雕文化的年轻人。

**差异化**：不是"怎么通关"而是"怎么被整蛊"——每一关都是一次认知颠覆。

## 二、设计原则

### 2.1 关卡设计铁律
1. **第一反应必翻车** — 玩家的直觉操作100%失败
2. **解法出乎意料** — 但失败后有合理提示
3. **翻车有奖励** — 失败动画、吐槽台词是游戏乐趣的一部分
4. **3次失败给提示** — 不卡关，不劝退

### 2.2 关卡模板
```
关卡N：{主题名}
├── 表面目标：{玩家以为要做什么}
├── 翻车方式：{常规操作怎么失败}
├── 真正解法：{另辟蹊径}
├── 整蛊动画：{专属失败动画}
└── 通关彩蛋：{专属通关庆祝}
```

## 三、技术架构

```
单文件HTML5游戏
├── Canvas渲染层
├── 关卡系统 (class L0X extends BaseLevel)
├── 音频系统 (Web Audio API)
│   ├── 背景音乐 (lo-fi pentatonic)
│   ├── 音效反馈 (beep系统)
│   └── 语音鼓励 (Web Speech API)
├── UI系统
│   ├── 关卡选择栏
│   ├── 成就弹窗
│   └── 音量面板(可拖拽)
└── 数据持久化 (localStorage)
```
